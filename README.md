# 회전체 작품 AR 갤러리 · 인하대 특강 (2026. 11. 4.)

인하대학교 수학교육과 특강에서 만든 회전체 작품과, 참고용 구월중 1학년 7반 학생 작품을 AR로 보는 사이트.
학교 갤러리(j333333766-hub/rotation-ar-gallery)의 build.py 를 고친 것.

## 작품 올리기
1. 연수생은 그림판3D `저장 → AR 웹뷰어 (ZIP)` 파일을 `OneDrive - 구월중학교\2026학년도\회전체 만들기 3D 모델 제출(연수용)`에 올린다(복제판 회전체 만들기 39쪽 링크, 파일 이름 = 학번이름.zip).
2. 이 폴더에서 `python build.py` → `works/`와 `index.html`을 새로 만든다.
3. `git add -A && git commit -m "작품 갱신" && git push` → 1~2분 뒤 Pages 반영.

## 규칙
- 연수용 폴더의 ZIP 은 모두 '인하대 특강' 묶음(폴더 `works/inha-학번/`). 단, 학교 원래 제출 폴더에 같은 이름이 있는 파일(학생 사본)은 뺀다.
- 참고 묶음은 학교 원래 제출 폴더(`...\회전체 만들기 3D 모델 제출`)에서 `REF_CLASS`(107 = 1학년 7반)만.
- 공개 사이트라 이름은 가린다(`10701 홍*동`). 이름만 쓴 파일(`홍길동.zip`)도 `홍*동`.
- 첫 화면 칩: 전체 · 인하대 특강 · 참고 · 구월중 1학년 7반. 연수생 작품이 없으면 안내 문구가 뜬다.
